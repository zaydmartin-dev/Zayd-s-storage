# Python Review

## Python Basics

### List
What is a list, and when would you use one in Python?  
A list is an ordered, mutable collection of items. You would use it when you need to store multiple values and change them later, such as adding, removing, or updating items.

### Tuple
How is a tuple different from a list?  
A tuple is similar to a list, but it is immutable, which means it cannot be changed after it is created. Tuples also use parentheses.

### Set
What makes a set different from a list?  
A set is an unordered collection of unique items. It is useful when you want to remove duplicates, and it uses curly braces.

### Mutable
What does it mean if an object is mutable?  
A mutable object can be changed after it is created.

### Immutable
What does it mean if an object is immutable?  
An immutable object cannot be changed after it is created.

## Functions & Dictionary Methods

### len()
What does the len() function return?  
The len() function returns the number of items in an object.

### .get()
Why would you use the .get() method with a dictionary?  
You would use .get() to safely retrieve a value from a dictionary without causing an error if the key does not exist.

### .length()
Is .length() a valid Python method? If not, what should you use instead?  
No, .length() is not a valid Python method. You should use len() instead.

### .keys()
What information does the .keys() method return?  
The .keys() method returns all the keys in a dictionary.

### .values()
What information does the .values() method return?  
The .values() method returns all the values in a dictionary.

## Challenge Questions

1. Which Python collection type cannot be changed after it is created?  
A tuple.

2. Which collection automatically removes duplicate values?  
A set.

3. What is the difference between a list and a dictionary?  
A list stores items in an ordered sequence, while a dictionary stores data as key-value pairs.

4. Which list method would you use to add an item to the end of a list?  
You would use append().

5. Which dictionary method would you use to safely retrieve a value by its key?  
You would use get().

6. What is the difference between a class and an object?  
A class is a blueprint or template for creating objects, while an object is an instance of a class.

7. How do inheritance and polymorphism work together in object-oriented programming?  
Inheritance allows a child class to reuse code from a parent class, and polymorphism allows different classes to use the same method name in different ways.

8. Why are constructors important when creating objects?  
Constructors are important because they initialize an object’s attributes and set up the object when it is created.
